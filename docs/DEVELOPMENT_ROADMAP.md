# Development Roadmap

Each milestone should be implemented and verified before beginning the next.

1. **Project initialization** - Godot project, Git, documentation, and folder scaffold. Current milestone.
2. **Cards and decks** - Card data, ownership, shuffle/deal behavior, and reusable placeholder visuals. In progress; implementation and focused test script are present, but the test still needs a Godot run.
3. **Traditional cribbage** - Deal, discard, crib, cut, and hand scoring.
4. **Pegging** - Turn order, legal plays, scoring, go, and last-card rules.
5. **Opponent AI** - Baseline discard and pegging decisions.
6. **Encounters** - Targets, hand limits, outcomes, sudden death, and retries.
7. **Roguelite progression** - Ten stages, encounter selection, bosses, rewards, and currency.
8. **Perks** (done) - Data-driven resources, starter selection, triggers, and effects.
9. **Shop and economy** - Inventory, rarity, pricing, purchases, and retry costs.
10. **Playable prototype** - Complete run loop, functional placeholder UI, and end-to-end testing.
11. **Art and polish** - Replace placeholders and add requested presentation improvements.

Do not start a later milestone until the current milestone's tests and project checks pass and the user approves continuing.
