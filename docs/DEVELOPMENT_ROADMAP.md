# Development Roadmap

Implement and verify one milestone at a time. Do not begin the next milestone
until the current one is tested and approved.

1. **Project initialization** — Godot project configuration, folder structure,
   README, Git ignore rules, and opening/running verification.
2. **Cards and decks** — card data, ownership, shuffle, deal, and reusable
   placeholder card visuals.
3. **Traditional cribbage** — deal, discard, crib, cut, and hand scoring.
4. **Pegging** — turn order, legal plays, scoring, Go, and last-card rules.
5. **Opponent AI** — baseline discard and pegging choices.
6. **Encounters** — targets, hand limits, completion, sudden death, and retries.
7. **Roguelite progression** — stages, encounter selection, bosses, rewards,
   and currency.
8. **Perks** — data resources, starter selection, triggers, and shop perks.
9. **Shop and economy** — inventory, rarity, pricing, purchases, and retry costs.
10. **Playable prototype** — full run loop, functional placeholder UI, and
    complete-run testing and balance.
11. **Art and polish** — replace placeholders and add requested presentation,
    audio, animation, and UI refinements.

## Current status

Milestone 1 is in progress. This repository contains the project shell and a
placeholder launch screen only; gameplay systems and their tests have not been
implemented.
