# Skunked – Asset Shopping List

Everything is currently a placeholder (colored panels / text). Nothing below is required to run the game; this is the full list to search for or create. Suggested style: pixel art matching the existing card set (88x124 cards, nearest-neighbour scaling). Free/CC0 sources: itch.io, OpenGameArt, Kenney.nl, freesound.org.

Legend: **Have** = already in `assets/cards/`.

| Asset | Spec | Status |
